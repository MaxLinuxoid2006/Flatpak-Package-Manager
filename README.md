# Flatpak-Package-Manager
Данный скрипт предназначен для управления пакетами Flatpak для новичков исключительно для дистрибутивов Linux. Для того чтобы активировать данный скрипт вам нужно прописать команду в терминале: python3 Flatpak-Package-Manager.py или установить интерпретатор Python для автоматического запуска скрипта из файлового менеджера.
